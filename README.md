# Hospital Queue Management System (C Project)

## 📖 Description
A simple console-based project in C language that simulates a **hospital queue system**.  
Patients are managed using the **FIFO (First In First Out)** principle with the help of a queue data structure.  
This project demonstrates **queue implementation in C** and its real-life application in hospital management.

## 🛠️ Technologies Used
- C Programming Language
- Queue Data Structure (Array Implementation)

## 🚀 Features
- Add Patient (enqueue)
- Serve Patient (dequeue)
- View Next Patient (peek)
- Display All Patients in Queue
- Exit the system
